Cryptanalysis of Vigenère Cipher using Kasiski Examination and Frequency AnalysisCourse/Assignment: Lab Assignment 6Group Number: Group 8Assigned Input: Ciphertext-2 (Even Group Numbers)📌 Project OverviewThis project implements a complete pipeline to perform cryptanalysis on a Vigenère-encrypted ciphertext without prior knowledge of the encryption key or key length. The pipeline employs two primary cryptanalytic methodologies:Kasiski Examination: Identifies repeated n-gram patterns in the ciphertext, calculates their distance intervals, and analyzes factor frequencies to derive candidate key lengths.Index of Coincidence (IC) Analysis: Measures letter probability distribution within Caesar-ciphered groups to pinpoint the most probable key length (IC close to English text $\approx 0.067$).Frequency Analysis & $\chi^2$ Goodness-of-Fit: Computes single-letter frequency shifts across Caesar-ciphered sub-groups to reconstruct the Vigenère key and decrypt the message.🛠 Required FunctionsThe implementation is structured into the following core functions:FunctionDescriptionclean_ciphertext()Preprocesses input by stripping non-alphabetic characters and converting text to uppercase.find_repeated_patterns()Locates repeating $n$-grams (length 3 to 5) and records their positional indices.calculate_distances()Computes pairwise index distances for all identified pattern occurrences.find_factors()Evaluates candidate key length factors (from 2 up to distance) and aggregates frequencies.kasiski_analysis()Coordinates pattern identification, distance calculation, and factor analysis.calculate_ic()Computes the Index of Coincidence ($IC$) for a given block of text.split_into_groups()Slices the ciphertext into $N$ sub-streams based on a candidate key length $N$.frequency_analysis()Generates letter frequency distribution vectors for each sub-stream group.find_shift()Calculates the optimal Caesar shift per group using chi-squared English distribution matching.find_key()Reconstructs the full key string by combining individual group shift values.vigenere_decrypt()Decrypts the ciphertext given the recovered key.vigenere_encrypt()Encrypts plaintext given a key (used for verification).verify()Re-encrypts recovered plaintext and verifies matching equality with the cleaned ciphertext.📁 Directory StructurePlaintext.
